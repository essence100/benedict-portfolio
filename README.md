# Benedict Portfolio Website 🚀

A modern responsive personal portfolio website built to showcase my skills, services, projects and professional profile as an IT Specialist.

---

## 👨‍💻 About The Project

**Benedict Portfolio** is a personal website designed to introduce my IT expertise, highlight my technical skills, display completed projects and provide a simple way for clients or companies to contact me.

The website focuses on:

- IT Support services
- Software installation
- Hardware maintenance
- Web development skills
- Professional project showcase
